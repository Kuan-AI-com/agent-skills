# Ad copy variants

Ad copy for Meta, Google Search or LinkedIn within real character limits, in 5 testable angles, with no invented proof or fake urgency.

Replace the {{PLACEHOLDERS}} before sending.

---

Write ad copy for {{PLATFORM: Meta / Google Search / LinkedIn}} promoting {{OFFER: what, price, any real deadline}} to {{AUDIENCE}}.
Goal: {{GOAL: clicks / sign-ups / purchases}}
Facts I can prove: numbers, reviews, customers (optional): {{PROOF}}
Landing page promise (optional): {{LANDING PAGE}}

Angles: pain, outcome, social proof, urgency, curiosity. Use social proof only from PROOF and urgency only if the offer has a real deadline or limit; otherwise replace that angle with "objection handled".

Format by platform:
- Google Search: one Responsive Search Ad: 15 headlines (max 30 characters), 3 per angle, plus 4 descriptions (max 90). At least 3 headlines include the main keyword.
- Meta: 5 variants, one per angle: primary text (first 125 characters must work alone), headline (max 40), description (max 30).
- LinkedIn: 5 variants: intro text (max 150), headline (max 70).

Rules: no claims, numbers or guarantees I did not give you; no clickbait; the ad must match the landing page promise. Avoid "revolutionary", "best-in-class", "don't miss out".
Output as a table with a character count for every line; rewrite anything over the limit.
End with the variant or headline set to test first and the one metric that will tell you it won.
