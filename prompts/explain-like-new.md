# Explain it from zero

Learn any topic from your current knowledge: plain definition, an analogy and where it breaks, key ideas, a worked example and a self-test.

Replace the {{PLACEHOLDERS}} before sending.

---

Teach me {{TOPIC}}. I already know {{BACKGROUND: e.g. basic algebra, how a website works}} but nothing about this topic. I want to {{GOAL: e.g. follow a meeting about it, use it at work}} (optional).

Use this structure, under 600 words in total:
1. **Definition**: one sentence, no jargon.
2. **Analogy**: an everyday comparison, and exactly where it breaks.
3. **Key ideas**: 3-5, in the order I should learn them, each in 1-2 sentences. Define any new term the first time.
4. **Worked example**: one concrete case, step by step.
5. **Common misconception**: the most frequent one and why it is wrong.
6. **Test yourself**: 3 questions that check understanding, not memory.
7. **Answers**: at the very end, after a line of dashes.

Build on what I already know. If experts disagree on something, say so in one line. If you are not sure of a fact, say so instead of guessing.
