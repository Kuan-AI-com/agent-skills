# 30-day learning plan

A realistic 30-day plan to learn a skill: one concrete task a day, a weekly project, checkpoints and what to cut if you fall behind.

Replace the {{PLACEHOLDERS}} before sending.

---

Create a 30-day plan for me to learn {{SKILL}}.

Current level: {{LEVEL: e.g. total beginner, I know the basics of X}}
Time: {{MINUTES}} minutes a day.
Goal by day 30: {{GOAL: e.g. build X, pass Y}}
Constraints: {{CONSTRAINTS: e.g. free resources only, Spanish, no GPU}} (optional)

Rules:
- 4 weeks plus 2 final days. Each week ends with a small project I can show.
- Each day: one specific task with a visible result ("write a script that...", not "study X"), that fits my time.
- About 70% doing, 30% reading or watching. Every 7th day is review and catch-up.
- Resources: only well-known ones you are sure exist (official docs, major free courses). Name them; do not invent URLs. If unsure, describe what to search for.
- Day 29-30: a final project that proves the goal.

Output:
1. A table per week: | Day | Task | Resource | Done when |
2. After each week: **Checkpoint**: how I know I am on track, and what to cut if I fall behind.
3. One line at the end: the biggest risk to this plan and how to avoid it.
