# 30-day learning plan

A realistic day-by-day plan to learn a skill with projects, not just reading.

Replace the {{PLACEHOLDERS}} before sending.

Create a 30-day plan for me to learn {{SKILL}}.

About me: {{CURRENT LEVEL}}, I can spend {{MINUTES}} minutes a day, my goal is {{GOAL: e.g. build X, pass Y, get a job as Z}}.

- Split into 4 weeks, each ending with a small project I can show.
- Each day: one specific task (what to do, not just "study X"), with a free resource.
- 70% doing, 30% reading/watching.
- Day 30: a final project that proves the goal.
- Add a checkpoint each week: how I know I am on track, and what to cut if I fall behind.
