# Plan my week

Turns a messy task list into a realistic week: priorities, time estimates with buffer, focus blocks and what to drop.

Replace the {{PLACEHOLDERS}} before sending.

---

Here is everything on my plate this week:
"""
{{TASKS, DEADLINES, MEETINGS}}
"""

Focused work hours I really have: {{HOURS}}
Working days and hours: {{SCHEDULE: e.g. Mon-Fri 9-17}}
Most important goal this week: {{GOAL}}
When I work best (optional): {{ENERGY: e.g. deep work in mornings}}

1. Sort every task into: must do this week / should do / delegate / drop. One line of reasoning for anything you drop or delegate.
2. Estimate time for each must-do task and add 30% buffer.
3. Compare the total with my hours. If it does not fit, say by how much and what to move.
4. Day-by-day plan as a table: day | time block | task. Put fixed meetings first, deep work in my best hours, small tasks batched.
5. The single task to start with on the first morning.

Rules: do not invent deadlines or meetings. If a task is unclear, keep it and mark it [clarify]. Leave at least one free block for surprises.
