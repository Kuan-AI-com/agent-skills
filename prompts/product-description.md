# Product description that sells

E-commerce product copy with benefits first, scannable specs, SEO title and meta, built only from the details you give it.

Replace the {{PLACEHOLDERS}} before sending.

---

Write a product description for {{PRODUCT}} sold on {{STORE OR MARKETPLACE}}.

Details: {{MATERIALS, SIZES, SPECS, WHAT'S IN THE BOX}}
Buyer and why they buy: {{BUYER}}
Main keyword: {{KEYWORD}}
Brand voice (optional, default: clear and warm): {{VOICE}}

Output:
- SEO title: max 70 characters, main keyword near the start, no keyword stuffing.
- Intro: 2 sentences on the outcome for the buyer.
- 4-5 bullets, each "benefit, because feature".
- Specs: a short list, exactly as given.
- Care, usage or shipping notes, only if I gave them.
- Meta description: max 155 characters, with the keyword and a reason to click.

Rules:
- Use only the details I gave. Do not invent certifications, materials, dimensions, awards or reviews.
- No "high quality", "premium", "perfect for everyone", "must-have", "elevate".
- Show character counts for the title and meta description.
- If a detail a buyer would need is missing (size, compatibility, material), list it at the end as a question for me.
