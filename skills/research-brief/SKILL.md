# Research brief

## 1. Frame
- Restate the question in one sentence, including scope: geography, time period, population, units. Ambiguous scope that changes the answer: ask once, or pick one and say so.
- Break it into 3-5 sub-questions whose answers together answer the question.

## 2. Search
- No web or document access: say so at the top, answer from knowledge, and label the whole brief "unverified, from model knowledge (cutoff <date>)". Do not fake citations.
- Source priority: primary data and official sources (statistics offices, filings, regulators, standards, docs, peer-reviewed papers) > reputable reporting that cites them > everything else. Trace secondary claims back to the primary source when you can.
- Note each source's publication date. For fast-moving topics (prices, laws, software, AI) prefer the last 12 months and flag older sources.
- Open every source you cite. A search snippet is not a source. Paywalled: cite only what is visible and say so.

## 3. Stop when
- each sub-question has two independent sources that agree, or
- you have done about 3 searches per sub-question without new information: record it as unknown.
Do not keep searching to make the brief longer.

## 4. Check numbers
For each figure: same unit, year, geography and definition as the question? "Unemployment 4%" from a different country or year does not answer it. Quote figures exactly as published with their date.

## 5. Write the brief

**Answer**: 2-4 sentences, bottom line first, with the confidence level.

**Key findings**: bullets. Each: the claim, the number if any, source name + link + date.

**Where sources disagree**: who says what, and the likely reason (definitions, methods, dates, interests).

**Unknown / not found**: what you looked for and could not establish.

**Confidence**: high (multiple primary sources agree), medium (one primary or several secondary), low (indirect or old evidence). One line on what would change it.

## Rules
- Never invent a source, URL, author, quote or number. A missing answer is a valid result.
- Separate your inference from the sources: "Sources show X; this suggests Y (my inference)."
- Keep it under one page unless the user asks for depth.
