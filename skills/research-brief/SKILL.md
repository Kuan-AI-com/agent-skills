# Research brief

1. Restate the question in one sentence and list the 3-5 sub-questions that answer it.
2. Search for each sub-question. Prefer primary sources: official docs, papers, filings, datasets. Note the date of each source.
3. Write the brief:
   - **Answer**: 3-4 sentences, the bottom line first.
   - **Key findings**: bullets, each with its source link.
   - **Disagreements**: where sources conflict and why.
   - **Confidence**: high / medium / low, and what would change it.
4. Label every claim as a fact (sourced), an estimate (with method) or an opinion (whose).
5. Never cite a source you did not open. If you could not find something, say so.
