# Email replies

1. List every question and request in the incoming email. The reply must answer all of them, in the same order.
2. Match the sender's register: formal stays formal, short and casual stays short.
3. Structure:
   - first line answers the main point (no "I hope this email finds you well")
   - details, one short paragraph each
   - one clear next step with a date if relevant
4. If you lack information to answer something (a price, a date), leave a visible [placeholder] instead of inventing it.
5. Keep it under 150 words unless the email needs more.
6. Offer one alternative version only if the right tone is genuinely unclear (e.g. firm vs. friendly refusal).
